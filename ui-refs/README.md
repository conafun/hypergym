# UI 参考图收集处

把参考 App 的截图直接丢进这个文件夹（png / jpg / webp / gif 都行），
然后告诉 AI "我放了几张图"，AI 会用 read_image 打开看图并分析界面设计。

建议命名带上出处和页面，比如：
- hevy-home.png          Hevy 首页
- hevy-muscle.png        肌群分布图
- strong-log.png         Strong 训练记录页
- strong-chart.png       力量曲线图
- boostcamp-feed.png     社交动态流
- liftlog-diary.png      日记页

图片里的 UI 可以直接被拆解成设计要素（配色/卡片/图表/间距/字体层级），
然后照着在 Compose 里复刻或改造。
